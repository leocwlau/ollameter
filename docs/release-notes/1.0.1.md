# Ollameter 1.0.1

Released: 2026-11-18
App version: 1.0.1
Bundle build number: 1.0.1

This is a bug-fix release with no breaking changes and no data migration.

## Highlights

-   Paste API keys using `Command-V` or `Control-V`.
-   Unpaid accounts now display their zero-balance state correctly.

## Fixed

### API key entry

-   Added standard paste support for the API key field.
-   Both `Command-V` and `Control-V` now insert clipboard text into the focused API-key entry field.

### Unpaid accounts

-   Ollameter no longer treats a valid unpaid-account balance response as an unexpected format.
-   When `balance_usd` and `allowance_usd` are both zero, the popover now shows:
    -   `Balance` as `$0.00 / $0.00`
    -   Usage and period bars at `0.0%`
    -   The neutral headline `--` with the caption `No allowance in this period`
    -   Purchased credits and reset details when available
-   The menu bar shows `--` because a zero allowance does not define a usage-pace percentage.

## Updating

1.  Quit any running copy of Ollameter.
2.  Run:


    ```sh
    ./scripts/build-app.sh
    ```

3.  Replace the existing app with the generated bundle:


    ```sh
    cp -R .build/release/Ollameter.app /Applications/
    ```

4.  Launch `/Applications/Ollameter.app`.

Because locally built apps are ad-hoc signed, macOS may ask for Keychain authorization after rebuilding or replacing the app.

-   Both paste shortcuts are covered by an application-menu regression test.
-   All unit tests passed.
